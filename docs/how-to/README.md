# How-To Guides

> **Problem-oriented** — Practical steps to help you solve a specific problem.

How-to guides assume you already have some familiarity with Open KLara and need to accomplish a particular task. They are goal-oriented and focused on practical outcomes.

## What belongs here

- Installation and deployment procedures
- Configuration guides for specific scenarios
- Troubleshooting guides
- Operational procedures (backup, upgrade, scaling)

## Guidelines for writing how-to guides

- Focus on **achieving a specific goal**
- Assume the reader has **basic knowledge** of the system
- Provide **flexible** instructions that can adapt to different situations
- Keep guides **focused** — one guide per problem
- Include prerequisites at the top
