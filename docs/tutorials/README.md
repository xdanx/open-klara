# Tutorials

> **Learning-oriented** — Lessons that take you through a series of steps to complete a project.

Tutorials are designed to help newcomers get started with Open KLara. Each tutorial walks you through a complete workflow from start to finish, explaining concepts along the way.

## What belongs here

- Step-by-step guides for beginners
- Getting started walkthroughs
- End-to-end examples that teach by doing
- First-time setup experiences

## Guidelines for writing tutorials

- Focus on **learning**, not on accomplishing a task
- Provide a **complete, working example** from start to finish
- Ensure the reader **achieves something meaningful** by the end
- Keep steps **concrete and reproducible**
- Explain the *minimum* necessary to proceed at each step
