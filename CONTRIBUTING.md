# Contributing to Open KLara

Thank you for your interest in contributing to Open KLara! This document provides guidelines and information for contributors.

## Getting Started

1. **Fork** the repository on GitHub.
2. **Clone** your fork locally:
   ```bash
   git clone https://github.com/<your-username>/open-klara.git
   cd open-klara
   ```
3. **Create a branch** for your changes:
   ```bash
   git checkout -b my-feature
   ```
4. Follow the [installation guide](docs/tutorials/installation.md) to set up a development environment.

## How to Contribute

### Reporting Bugs

- Use the [Bug Report](https://github.com/gajeshbhat/open-klara/issues/new?template=Bug_report.md) issue template.
- Include your OS, Python version, PHP version, and Open KLara version.
- Provide clear steps to reproduce the issue.

### Suggesting Features

- Use the [Feature Request](https://github.com/gajeshbhat/open-klara/issues/new?template=Feature_request.md) issue template.
- Describe the problem your feature would solve.
- Consider alternative approaches.

### Submitting Code

1. Make your changes in a feature branch (not `master`).
2. Keep commits focused and write clear commit messages.
3. Test your changes locally before submitting.
4. Open a pull request against the **master** branch.
5. Fill out the pull request template completely.

### Documentation

Documentation improvements are always welcome. Our docs follow the [Diátaxis framework](https://diataxis.fr/) and are organized under the `docs/` directory:

- `docs/tutorials/` — Step-by-step learning guides
- `docs/how-to/` — Task-oriented instructions
- `docs/explanation/` — Background and context
- `docs/reference/` — Technical reference

## Code Style

- **Python**: Follow [PEP 8](https://peps.python.org/pep-0008/) conventions.
- **PHP**: Follow the existing code style in the project.
- Keep changes minimal and focused on the issue at hand.

## Pull Request Guidelines

- One pull request per feature or fix.
- Update documentation if your change affects user-facing behavior.
- Ensure your changes don't break existing functionality.
- Be responsive to review feedback.

## Code of Conduct

Please be respectful and constructive in all interactions. We are committed to providing a welcoming and inclusive experience for everyone.

## Questions?

If you have questions about contributing, feel free to [open an issue](https://github.com/gajeshbhat/open-klara/issues/new) for discussion.
